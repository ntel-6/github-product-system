# Модель безопасности

- Bootstrap и audit не используют сеть.
- Секреты не входят в конфигурацию, шаблоны или тестовые данные.
- `.env`, ключевые файлы и private keys блокируются аудитом.
- Внешние GitHub Actions допускаются только по полному 40-символьному commit SHA.
- `pull_request_target` запрещён базовой политикой.
- Workflow получает только `contents: read`.
- Public-проект нельзя создать без явной лицензии.
- Publish, rulesets, environments, secrets и releases вынесены в отдельные явные операции.
- Аудит предупреждает о файлах от 25 МБ и отклоняет файлы от 50 МБ.
