# Вклад в продукт

1. Свяжите изменение с issue или кратко опишите проблему.
2. Делайте одну логическую задачу на ветку.
3. Добавляйте или обновляйте проверку поведения.
4. Запускайте `scripts/verify.ps1` до pull request.
5. Не смешивайте функциональные изменения с несвязанным форматированием.
6. Не добавляйте секреты и сгенерированные тяжёлые файлы.
