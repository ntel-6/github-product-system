# Политика безопасности

Не публикуйте уязвимость в обычном issue.

Используйте **Security → Advisories → New draft security advisory** в репозитории. Если private vulnerability reporting включён, используйте кнопку **Report a vulnerability**.

В сообщении укажите затронутую версию, минимальные шаги воспроизведения, возможное влияние и безопасный способ проверки исправления. Не прикладывайте реальные токены, ключи или персональные данные.
